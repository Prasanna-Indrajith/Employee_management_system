# Why PostgreSQL (short):

- **Reliable**, ACID-compliant, and well-suited for complex relational schemas.

- **Strong JSON support** (jsonb) for flexible fields (profile/settings) without sacrificing relational integrity.

- **Advanced features**: rich indexing (GIN/GiST), full-text search, partial indexes, stored procedures (PL/pgSQL).

- **Good tooling & ecosystem**: TypeORM/Sequelize/Knex/Prisma support, pg driver, pg-pool, migrations (Flyway, Liquibase, Flyway, or node-based like Umzug / Knex migrations).

- **Scales well vertically and horizontally** with read replicas and partitioning when needed.

- **Excellent community**, security, and monitoring tools.
